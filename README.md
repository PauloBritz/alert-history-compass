# Alert History Compass

Preciso que você crie um frontend com backend se necessário para apresentar dados que são gerados por um script que tenho aqui, o script recebe eventos gerados por ferramentas de monitoramento como zabbix, e outros, e com base nesse evento busca no historico de chamados do otrs eventos similares, para auxiliar o analista que for atender o evento na solução do problema. Com o historico de chamados, ele pode consultar as soluções que foram realizadas nos outros eventos atendidos nesses chamados. Então vou te encaminhar o script e exemplo da saida desse script, para poder construir a interface bonita e profissional que seja facil do analista ver. O script python está anexo
E a saida do script como exemplo para construir as telas que ajudaram o analista na analise está anexo também com a execução do script. Me impressione.
